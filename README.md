# Веб-сайт - КиноБаза - Учебное портфолио

Практическая работа №5 по дисциплине **"Веб-программирование"** (5 семестр).  
Проект представляет собой SPA-приложение "КиноБаза" - персональный каталог фильмов и сериалов с возможностью добавления, редактирования, фильтрации, поиска и подсчета статистики.

## Что тут вообще есть?

* **SPA-архитектура:** переключение между вкладками «Каталог» и «Статистика» происходит мгновенно, без перезагрузки страницы.
* **Умное добавление:** при выборе типа контента (фильм или сериал) форма в модальном окне подстраивается - меняются подписи полей, появляются поля для сезона и количества серий.
* **Поиск и фильтрация:** каталог фильтруется в реальном времени по названию, жанру, статусу и году. Все параметры поиска и сортировки сохраняются в sessionStorage и не сбрасываются при случайной перезагрузке вкладки.
* **Рейтинг и превью:** оценка ставится кликом по звездочкам (с эффектом при наведении). При вставке ссылки на постер картинка сразу отображается в окне предпросмотра.
* **История с памятью:** вся база фильмов хранится в localStorage - данные не пропадут при закрытии браузера. Карточки можно редактировать и удалять.
